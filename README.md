
# 📊 Sales Analytics & AI Business Intelligence Dashboard

## 👩‍💻 Author
Aarati Pawar

## 📌 Project Overview

This project is developed as part of the IBM SkillsBuild
Data Analytics with AI Academic Internship.

The project analyzes sales data and converts raw transactional
data into meaningful business insights using Python, Pandas,
Plotly and Streamlit.

## 🎯 Objectives

- Clean and preprocess sales data
- Perform Exploratory Data Analysis
- Calculate business KPIs
- Analyze sales and profitability
- Identify business risks and opportunities
- Build an interactive dashboard
- Prepare the project for AI-assisted business analysis

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- OpenPyXL
